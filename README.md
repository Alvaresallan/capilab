# CapiLab: Energia da Amazônia

Jogo educativo em pixel art sobre pré-tratamento de biomassa, desenvolvido no **CPBIO-UFMT**. Explore o laboratório com Julio, a capivara cientista.

## Jogar agora

**[Abrir CapiLab no navegador](https://alvaresallan.github.io/capilab/)** — sem instalação.

**[Baixar para Windows — v0.5.2](https://github.com/Alvaresallan/capilab/releases/download/v0.5.2/CapiLab-Windows-v0.5.2.zip)** — extraia o ZIP e abra CapiLab.exe.

## Controles e idiomas

- Computador: WASD/setas para andar; E para interagir; M para mapa; Tab para caderno; Esc para pausa.
- Celular: use a tela na horizontal e os controles de toque.
- Português, inglês e espanhol; configurações de acessibilidade no menu.

## Progresso no navegador

O progresso fica salvo no navegador e dispositivo utilizados. Não sincroniza entre aparelhos nem com a versão Windows. Limpar os dados do site pode apagar a partida; navegação privada pode impedir sua conservação.

Requer navegador com WebGL 2.0 e WebAssembly. Testado em Chromium no Windows, incluindo tela reduzida e controles de toque com mouse. Validação em aparelhos físicos com Safari/macOS/iPhone ainda pendente.

Se houver dificuldade no carregamento, use **Tentar novamente** ou **Abrir jogo diretamente**.
